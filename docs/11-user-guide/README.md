# Panduan Pengguna

Panduan per peran:
- Owner
- Super Admin
- Manajer Cabang
- Kasir (POS)
- Resepsionis
- Dokter Hewan
- Paramedis/Perawat
- Groomer
- Petugas Penitipan
- Admin Gudang
- Keuangan/Akuntan
- Pelanggan (Portal)

Setiap panduan mencakup: halaman yang tersedia, aksi utama, permission yang dibutuhkan, state kosong/loading/error, dan langkah-langkah alur kerja.
